## ⚙️ Requirements

* Windows 10 / 11
* Python 3.x

## 🚀 Installation & Usage

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/Samaanl/phonk-break-py
    ```

2.  **Navigate to the directory:**
    ```sh
    cd phonk-break-py
    ```

3.  **Install the required libraries:**
    ```sh
    pip install -r requirements.txt
    ```


5.  **Run the script:**
    ```sh
    python phonk_break_desktop.py
    ```
