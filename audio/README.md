# Phonk Break Audio Files

This directory should contain your phonk MP3 tracks.

## Required Files:

- `phonk1.mp3`
- `phonk2.mp3`
- `phonk3.mp3`
- `phonk4.mp3`
- `phonk5.mp3`

**Note:** The extension randomly selects one track each time - no specific order, just pure random vibes!

## How to Add Your Tracks:

1. Find 5 phonk tracks you want to use (short loops work best - around 10-15 seconds)
2. Name them `phonk1.mp3`, `phonk2.mp3`, `phonk3.mp3`, `phonk4.mp3`, `phonk5.mp3`
3. Place them in this `audio/` directory

## Recommendations:

- **Length**: 10-15 second loops work perfectly
- **Format**: MP3 for best compatibility
- **Size**: Keep files under 1MB each for fast loading
